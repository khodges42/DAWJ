# FreePats synthesizer sample collection

**Publisher:** FreePats project  
**Website:** https://freepats.zenvoid.org/  
**License:** Creative Commons CC0 1.0 Universal (see each pack license)

This collection contains 22 FreePats packs. Creators vary by pack; consult
each SOURCE.md and the preserved original README and license. This is not
the Frequency 303 MS-20 collection.

## Local organization

WAV files sit alongside each pack's documentation. Names use `S01 Instrument
Pitch.wav`, numbered within each pack in ascending SFZ root-key order,
then velocity and original filename. Pitch names use C4 = MIDI 60.
Original velocity labels and separate Left/Right files are retained.
Percussion names retain the original sound and variant identifiers.

Each sample-map.csv records original names, new names, and SHA-256 hashes.
All audio contents were verified unchanged. SFZ files were removed as
requested; sampler-settings.json preserves their complete original text
and a path translation for recovering loop points, envelopes, key ranges,
and other playback settings. It is archival data, not a playable sound bank.
Original downloaded .7z archives are retained unchanged.
