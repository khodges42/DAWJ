Session & sounds

Composition on selected deck

Replacing content requires the destination deck to have no playing parts, pending actions or periodic rules. The other deck can keep playing. New/Open replaces the whole session and requires output stopped.

Part sound & playback

Drop one WAV onto a part card, or onto this window for the editor's selected slot. WAV: mono/stereo PCM 16/24/32-bit or float32, prepared offline at 48 kHz. MP3 is not supported.

Loop frames refer to prepared 48 kHz audio. Musical length describes activity; no time stretching is applied. Global quantization still controls launches. Gain and cutoff use the performance surface; save captures their accepted targets. Saved periodic definitions are retained but require explicit re-arming. Pattern sequencing is deferred to Jam2.

Performance keys

Start output creates the session clock; Stop / reset closes it. There is no pause/resume transport in this engine. All actions use the scheduler's quantization. Select a slot without launching it, then use its buttons or Space. VOLUME/FILTER changes knob meaning only. Shift+V/F temporarily overrides the persistent mode.

Queued and playing states come from the engine. Receipt messages describe submission or rejection. Mixer controls show accepted targets; the meters show held diagnostic peaks. Stereo output has no isolated headphone cue. Four-channel routing requires physical verification.

Timeline projections marked ~ may skip because manual actions take precedence. Select markers using the menu or canvas; cancel the observed queued action or remove its rule in the inspector. Live phrase length is fixed; choose 4/8 bars before starting.

MIDI devices & mappings

Output values are ordinary Note/CC data, not RGB colors. No controller is required. A synth output is not a controller LED port.

Mapping editor
Absolute knobs use shared-core soft pickup when mode/selection/targets change. Relative mode uses two's-complement steps. Release a learned button before pressing it again. Conflicts and invalid maps are rejected by Rust.
Note / CC LED mapping
Native Appearance menu → Restore default interface (Ctrl+Alt+Shift+R) always remains available.

Skins & accessibility

Selection previews live for 15 seconds. Keep confirms it; timeout or Undo restores your saved interface. The native Appearance menu and --safe-mode work outside skin-styled controls.
