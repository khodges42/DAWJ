# M1.3 two-deck mixer

`StereoMixer` is independent of CPAL and can render deterministic offline
stereo f32 blocks. Two owned sources have independent cursors and EOF states.
Either source can be a tone or matching-rate stereo prepared PCM. Both advance
while enabled, including a deck muted by gain or the crossfader. One deck ending
does not stop the other; the stream finishes when both end. Sources are fixed
for a stream's lifetime: loading, seeking, pausing individual decks and looping
are future work. The M0 scheduler and its offline behavior are unchanged.

Per-deck gains are finite values in [0, 1]. Crossfader 0 selects A and 1 selects B.
The default equal-power curve uses cos(x*pi/2), sin(x*pi/2); the selectable linear
curve uses 1-x, x. Endpoints are exact. Equal power describes uncorrelated sources;
correlated sources can add at the center and need headroom/protection.

`MixerControl::set` validates and publishes both gains, position and curve in
one native x64 atomic u64 store. Each scalar is quantized to 16 bits (resolution
1/65535); endpoint values remain exact. Multiple writers are last-writer-wins.
The callback loads one coherent parameter word per frame without locks, retries,
allocation, filesystem access or ownership transfers. Combined deck/crossfader
coefficients ramp linearly from their current values to new targets over 20 ms
(rate/50 frames, minimum one). Curve changes use the same ramps. Startup starts
from zero; source starts/ends also receive 20 ms fades. Closely spaced changes
retarget from current values. Arbitrary discontinuities within supplied PCM are
not repaired. Abrupt stream errors/stop can still end queued audio.

The master applies 0.125 linear headroom (about -18 dB) before a stereo-linked
sample-peak limiter. Its fixed ceiling is +/-0.125 (about -18 dBFS), with instant
gain reduction, 100 ms exponential release and a final sample clamp. Linking
preserves the stereo balance during reduction. This simple conservative limiter
is not lookahead, true-peak protection or a guarantee of safe acoustic volume.
The CPAL legacy single-source path also gets the same hard sample ceiling;
M0/offline source samples are not modified. The limiter is basic master protection,
not an effects chain.

`MixerControl::peaks` returns post-limiter absolute L/R peaks held over the
mixer lifetime. Reads are independent atomic f32 bit patterns, not RMS, VU,
true peaks, or a transactional stereo snapshot. Peaks do not reset on read.
Master callback telemetry retains M1.2 clock semantics; `source_frames` is the
maximum deck cursor. Offline callers can inspect both cursors with `positions`.

## Demo and verified Windows behavior

```
# Help only, no sound:
cargo run -p audio-backend --example mixer --locked --offline
# Explicit playback, three-second countdown:
cargo run -p audio-backend --example mixer --locked --offline -- --play
# Optional fresh output-device ordinal instead of the OS default:
cargo run -p audio-backend --example mixer --locked --offline -- --play 0
```

The live check used the existing Windows default WASAPI endpoint,
`Speakers (HyperX Cloud III S Wireless)`, at 48000 Hz, two channels, f32,
default buffer request. Two very quiet 220/330 Hz sources (amplitude 0.02,
deck gains 0.5) ran for four seconds. Control-thread updates every 10 ms moved
the crossfader A -> center -> B using source-frame telemetry. Source frames:
192000; delivered frames including trailing silence: 202176; largest observed
callback: 1056 frames; finished=true; failed=false. Held post-limiter stereo
peaks were [0.001684967, 0.001684967] (about -55.5 dBFS).

Stream execution and meter results are verified, not human-confirmed audibility,
DAC timing, acoustic loudness or underrun absence. The default request does not
establish physical buffer size. No device purchase or configuration change was
needed. No additional live runs of the older, louder demos were performed.

Validation: Cargo fmt/check, workspace/all-target Clippy with warnings denied,
all workspace tests and exact Windows dependency inventory gate. Tests cover
curves, endpoint isolation, per-deck gains, stereo polarity, independent EOF,
mixed source types, coherent rejected updates, ramp bounds, callback partition
invariance, source fades, linked peak limiting/meters, disabled/error silence,
and the legacy adapter ceiling. Callback restrictions were reviewed in source;
allocator/deadline instrumentation and unplug recovery were not run. No external
dependency or licensing change; GPL-3.0-or-later compatibility is preserved.
